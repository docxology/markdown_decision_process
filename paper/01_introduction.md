# Introduction

Markdown exposes structural features that can be parsed, represented as a graph, sampled, and transformed by software. Markdown Decision Process explores decision-theoretic vocabulary as an interface for those operations. The name describes an engineering model; it is not evidence that syntactic state labels recover an author's intent or constitute a validated semantic POMDP.

The contribution of this revision is a description of inspectable software components and an evidence contract for evaluating them. It does not claim priority over all earlier document tools, superiority over neural models, or empirically validated document quality. Source code is the implementation authority, and an example or unit test establishes only the behavior exercised by that example or test.

The modular paper distinguishes conceptual background, implementation surfaces, prospective evaluation, and current evidence limits. The [evaluation evidence review](EVALUATION_EVIDENCE.md) identifies the withdrawn claim families and the records required to reintroduce any measured result. Historical deposits and dated files remain separate from this corrected source revision.
