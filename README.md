# Markdown Decision Process

Markdown Decision Process is a Python prototype for parsing and transforming Markdown, learning Markov transitions, and exploring document structure through graph, reward, and belief-update interfaces.

- [Documentation](docs/index.md) covers setup, examples, API, development, and verification.
- [Corrected manuscript source](docs/manuscript/README.md) describes the implementation, the checked-in example, and a prospective evaluation.
- [Historical publication](https://doi.org/10.5281/zenodo.17244387) and [archived outputs](paper/outputs/) identify the earlier edition.
