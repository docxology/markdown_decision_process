# Documentation collaboration

Start with the [documentation index](index.md). Put maintained user and technical guidance under this directory and add a link when introducing a guide. Keep examples consistent with the installed API and validate local links. The Sphinx builder reads the API directives in `reference/` and writes the site to `_build/`.

See [local build instructions](PUBLISHING.md) for the site and [manuscript verification](manuscript-build.md) for the corrected draft. Manuscript claim and evidence guidance is in [manuscript/AGENTS.md](manuscript/AGENTS.md).
